プライバシーポリシー

性界地図　制定日：2026年10月30日

性界地図（以下「本サービス」）は、性的な嗜好を分類した用語を地図のように表示し、利用者が共同で編集するWebサイトです。本サービスにおける利用者の情報の取り扱いを、以下のとおり定めます。

1. 取得する情報

  • ログイン時に連携先から受け取る情報：Google または GitHub でログインした場合、メールアドレス、表示名（アカウント名）、連携先の利用者ID。パスワードは受け取りません。
  • 編集の記録：用語の追加・変更・削除、親子関係の変更、通報の内容と、それを行った利用者、日時。
  • 18歳以上であることの確認日時：編集を始める前に利用者が確認した日時。
  • ブラウザ内に保存する情報：閲覧時の年齢確認の結果と、地図上の配置。これらは利用者のブラウザにだけ保存され、本サービスには送られません。

2. 利用目的

  • ログインと、編集できる利用者の確認のため
  • 編集履歴を表示し、誤った編集や荒らしを管理者が差し戻すため
  • 通報への対応と、規約に反する利用者の編集を停止するため

上記以外の目的には使いません。広告の配信や、第三者への販売は行いません。

3. 公開される情報

編集履歴には、編集した利用者の表示名が表示され、誰でも閲覧できます。メールアドレスは公開されません。

4. 外部サービスの利用

  • Supabase：利用者情報と地図のデータを保管します（東京リージョン）。
  • Google／GitHub：ログインに使います。
  • GitHub Pages：サイトを配信します。
  • Anthropic（Claude API）：似た用語をまとめる自動整理のため、用語の名前と親子関係を送ります。利用者の個人情報は送りません。

5. 第三者への提供

法令に基づく場合を除き、利用者の同意なく個人情報を第三者に提供しません。

6. 情報の削除

アカウントと、それに結びつく情報の削除を希望する場合は、下記の窓口からご連絡ください。削除後も、編集した用語そのものは地図に残りますが、編集履歴の記録者は表示されなくなります。

7. 年齢制限

本サービスは18歳以上の方を対象としています。18歳未満の方はご利用いただけません。

8. お問い合わせ窓口

GitHub の Issues からご連絡ください。

9. 改定

本ポリシーを改定する場合は、このページでお知らせします。
